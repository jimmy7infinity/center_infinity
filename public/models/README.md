## Truly free craft sources (CC0 / public domain)

Prefer CC0 so we don’t need attribution in the UI:

1. [Kenney](https://kenney.nl/assets) — Space Kit, Pirate Kit ships, etc.
2. [Quaternius](https://quaternius.com/) — low-poly spaceships, often CC0
3. [Poly Pizza](https://poly.pizza/) — filter by CC0
4. [OpenGameArt](https://opengameart.org/) — search “spaceship” + CC0
5. [Sketchfab](https://sketchfab.com/search?q=spaceship&features=downloadable&licenses=322a749bc8cd4e75&type=models) — filter Downloadable + CC0

Drop a `.glb` in this folder and point `ShipModel` at it. Recoloring still happens in code.
